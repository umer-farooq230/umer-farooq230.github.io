<figure><img alt="" src="https://cdn-images-1.medium.com/max/828/1*el0CtVdEy3nXoey8A5-fbg.jpeg" /><figcaption>Image Credits: O’Reilly Media</figcaption></figure><p>Let’s understand what gradient descent is in Machine Learning and how it works</p><p>This is the most important step in any Neural Network because in this step we will see the math behind a machine “learning” how to adapt to different inputs</p><p>We will use MNIST dataset in which there are thousands of examples of handwritten numbers from 0 to 9</p><h4>Cost/Loss Functions</h4><p>We always split our data into 2 separate sets</p><ol><li>Training Data</li><li>Testing Data</li></ol><p>suppose our desired number is 9</p><h4>Structure of Neural Network</h4><p>Suppose there are 4 total layers in this network where 2 are hidden layers and the other two are input and output layers respectively. The network in the first hidden layer will fetch the edges of the images and pass the information to the next hidden layer where it does the same on the structure of the input letter like the circle at the top of number 9 and a straight line below.</p><p>While training we feed our neural network with training data and make sure to shuffle it (so each value has an even probability of occurrence). As our given values have a totally random order, it is very possible that our Neural Network will be horrible at predicting the number at first (referring to the handwritten numbers data). It will give each neuron some value whereas we only want to give value to the neuron that represents our desired number</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/800/1*pOTqngRhsIqBnHZ9iNpSJQ.png" /><figcaption>MNIST dataset</figcaption></figure><p>So whenever our model predicts a number wrong we have to tell it somehow that “No this prediction is wrong!” How do we do it?</p><p>Mathematically speaking we develop a <strong>Cost Function </strong>in which we take the predicted wrong value, subtract it from the true values, square them, and finally add them to a single value. A Python code doing a cost function looks like this</p><pre>import math<br><br>predicted_value = [.01102, .05796, .09402, .07745, .08499]<br>true_value = [0.00, 0.00, 0.00, 1.00, 0.00]<br><br>sum_squared = 0<br><br>for i,j in zip(predicted_value, true_value):<br><br>        k = (i-j)**2<br>        sum_squared += k<br><br>print(sum_squared)</pre><p>Let’s look into a graph. Another name for gradient descent is minima. A minima is the last point on a curve given any value. We start at a point anywhere in the range from 0 to 1</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*1JhPIwGaLDO_MWN2fNWILw.jpeg" /><figcaption>By <a href="https://commons.wikimedia.org/w/index.php?curid=102907088">Serge Helfrich</a> — Own work, CC BY-SA 4.0,</figcaption></figure><p>and Then after finding the slope for each of our test inputs, we can find out whether our value should go on the positive side or negative side to find the lowest point. <strong>Minimizing the cost function</strong> <strong>is the goal of gradient descent</strong></p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*iqgl08Z9BoaHMRknnh43cQ.jpeg" /><figcaption>By <a href="https://commons.wikimedia.org/w/index.php?curid=102907088">Serge Helfrich</a> — Own work, CC BY-SA 4.0</figcaption></figure><h3>Gradient Descent</h3><p>Consider two inputs X and Y on a plane, instead of finding the slope multiple times our question should be which is the fastest way we should step in so that our output decreases? just like stepping downhill</p><p>In multivariable calculus, the <strong>gradient</strong> is a vector that points in the direction of the steepest ascent of a multivariable function. Simply put it points the direction uphill. Taking the negative of this function will give us the direction of the downhill</p><pre>Gradient = ∇f(x,y) <br>Gradient_Descent = -∇f(x,y)</pre><p>The algorithm of a gradient descent is:</p><ol><li>Calculate ∇f</li><li>A small step in -∇f</li><li>repeat</li></ol><p>This repetition of small steps to -∇f is called the <strong>Gradient Descent.</strong></p><p>These <strong>small steps </strong>are also called<strong> the learning rate.</strong> The lower the learning rate the more efficient our network is and will learn accurately. Suppose we take big steps walking downhill it is not safe and good for us rather we take small and easy steps. It may take longer but we will reach there safe and sound. Learning Rate works exactly like that. We will see more about it in the next part</p><p>Think of gradient descent as trying to find the lowest point while walking downhill. For each step, the network adjusts its weights to move closer to this “minimum” value.</p><p>Another way of putting this into visualization is Gradient Descent tells us for each value of the vector which one should increase or decrease to find its minima and which variable impacts the function most. For example, if we have a function like</p><pre>x=1<br>y=1<br><br>∇f(1,1) = [3,1]</pre><p>We can say that X has more impact than Y. That is how our Network grows with each step and minimizes the cost function.</p><p>Gradient Descent and cost functions are applied in <strong>Backward Propagation </strong>which we will cover in the next part but this alone is amazing how any machine if trained correctly can decide with great accuracy</p><img src="https://medium.com/_/stat?event=post.clientViewed&referrerSource=full_rss&postId=8686bdebfe64" width="1" height="1" alt=""><hr><p><a href="https://towardsdev.com/what-is-gradient-descent-intelligence-for-everyone-part-3-8686bdebfe64">What is Gradient Descent (Intelligence for Everyone Part-3)</a> was originally published in <a href="https://towardsdev.com">Towards Dev</a> on Medium, where people are continuing the conversation by highlighting and responding to this story.</p>
