Stick around to unlock the secrets I’ve uncovered on this fascinating journey.</p><h3>Phases</h3><p>There are Four Phases in this article. Complete them in the same order and then move forward.</p><h3>Phase 1: Foundations</h3><h3>Python</h3><p><a href="https://www.python.org/downloads/">Install Python</a> (get the latest)</p><p><a href="https://code.visualstudio.com">Install Vscode</a></p><p>I mean this is an obvious one but still, some people just hear about the new trend of ML and want to make ChatGPT. This is not possible. You have to learn Python and get a good grip on its fundamentals like loops, functions, lists, tuples, dictionaries, list comprehension.</p><p>First of all, learn the syntax from <a href="https://www.w3schools.com/python/default.asp"><strong>W3school</strong></a></p><p>Then to projects. Get Ideas for beginner projects from <a href="https://www.geeksforgeeks.org/python-projects-beginner-to-advanced/"><strong>Geeks for Geeks</strong></a></p><p>(Don’t listen to the “must have projects in resume” on YouTube)</p><p>Spend at least 3 months. The first month will be just learning and learning. Then the rest of the two months will be projects and more projects. You can adjust according to your level of understanding. <strong>You will be good when you can use your logic instead of looking at the code or tutorial.</strong></p><p>Directories are a common term for folders. To use datasets(explained below) your Python file and dataset should be in the same Directory</p><h4>When are you ready for the next phase?</h4><p>You are ready for the next phase when you are able to:</p><ul><li>Write Python code without tutorials.</li><li>Successfully completed at least three small projects.</li></ul><h3>Phase 2: Exploring Libraries</h3><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/0*p-jGOYJFdVBgf-fX" /><figcaption>Photo by <a href="https://unsplash.com/@hishahadat?utm_source=medium&amp;utm_medium=referral">Shahadat Rahman</a> on <a href="https://unsplash.com?utm_source=medium&amp;utm_medium=referral">Unsplash</a></figcaption></figure><p>Now that you have basic knowledge of Python. There are some libraries that will make your coding life easier. Libraries are already written pieces of code that you can take and use it as your own.</p><p>To install the libraries, open the terminal and write <em>pip install [library name] or !pip install [library name] (for </em><a href="https://colab.research.google.com"><em>Google collab</em></a><em> only)</em></p><h4>Pandas</h4><p>This library will help you manage large files AKA datasets easily. Learn from <a href="https://www.w3schools.com/python/pandas/default.asp"><strong>W3school</strong></a><strong> </strong>or<strong> </strong><a href="https://youtu.be/tRKeLrwfUgU?feature=shared"><strong>Nicholas</strong></a><strong>. </strong>This will be easy to learn.</p><h4>Numpy</h4><p>The most common library to do matrix multiplication. Because everything will be in Matrices. Learn basics from <a href="https://www.w3schools.com/python/numpy/default.asp"><strong>W3school</strong></a><strong>.</strong></p><h4>Matlplotlib</h4><p>As a Machine Learning engineer, you are always making calculations and manipulating numbers. Matplotlib will help you turn your numbers into visual graphs and help you better understand what are you doing. Something like this</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/589/1*hMUD9bEDjQhyrvCyMjZBRA.png" /><figcaption>Source: from <a href="https://www.w3schools.com/python/python_ml_confusion_matrix.asp">W3school</a></figcaption></figure><p>Learn Basic syntax from <a href="https://www.w3schools.com/python/matplotlib_intro.asp"><strong>W3School</strong></a></p><p>To make your graphs more visually appealing <a href="https://www.practicaldatascience.org/notebooks/class_5/week_5/46_making_plots_pretty.html">Read This</a></p><h4>Kaggle and Datasets</h4><p>Datasets are collections of big data converted into rows and columns which are mostly in Excel files. <a href="https://www.kaggle.com"><strong>Kaggle</strong></a> is a site for already-built datasets. <strong>Practice Pandas and Numpy</strong> (at least 2 months).</p><p>You can practice on this <a href="https://www.kaggle.com/datasets/uciml/iris"><strong>dataset</strong></a><strong> </strong>(Hit download). When you’ll go to an interview and they ask: “How do you handle model drift in production?” or “How can other people use your model?” you’ll be be blank.</p><p><strong>Note: Deployment is a practice-first concept and not course-first. You can just take a crash course and learn from the documentation while making a project (It’s the most Intuitive way)</strong></p><p>One thing to must note is different techniques have different purposes. They combine to make one full system</p><pre>| Technique  | What It Actually Is       |<br>| ---------  | ------------------------- |<br>| API        | Serving method            |<br>| Docker     | Packaging method          |<br>| MLflow     | Lifecycle management tool |<br>| Cloud      | Infrastructure location   |</pre><p>Now, as this is a more software engineering concept, you either have no experience with the tools and techniques or you have experience with the fundamentals of these concepts not specifically in ML. So I’ll target both and give resources accordingly</p><p>Some of the different techniques of Deployment are:</p><h4>1. API Deployment</h4><p>APIs can serve as a midpoint between users and an application (containing your model).</p><p><strong>A simple API architecture:</strong> Client → API → Model → Response</p><p>If you’re new to APIs:</p><ol><li><a href="https://youtu.be/5atR70lV1fs?si=W6jZwJ7lCSwDHxP9">APIs 101</a> (A crash course) (YouTube)</li><li><a href="https://roadmap.sh/api-design">Roadmap to API Development</a></li><li><a href="https://www.datacamp.com/courses/introduction-to-apis-in-python">Introduction to APIs in Python</a> (Datacamp Course) (Free)</li><li><a href="https://www.udemy.com/course/fastapi-the-complete-course/">FastAPI Complete Course 2026</a> (Udemy) (Paid)</li></ol><p>After you’ve got the basics then it’s easy and apply these techniques in ML</p><p>If you’ve experience with APIs:</p><ol><li><a href="https://youtu.be/5PgqzVG9SCk?si=F904MkC8OgQKHl_h">Creating APIs For Machine Learning Models</a> (A Crash Course) (YouTube)</li><li><a href="https://youtu.be/0sOvCWFmrtA?si=Q_V0YGd6fEGup7Pr">Python API Development</a> (19 hour course) (YouTube)</li><li><a href="https://www.udemy.com/course/nlp-with-bert-in-python/">Deploy ML models In Production with FastAPI and Docker</a> (Paid)</li></ol><h4>2. Containerization</h4><p>Containerization means a <strong>sealed box</strong> for your project. Inside the box, you put:</p><ol><li>Your model</li><li>Code</li><li>All libraries</li><li>The exact Python version</li></ol><p>When someone runs that box on their computer, it works exactly the same way it worked on yours. No “it works on my machine” problems.</p><p>Docker is a platform that helps us containerize the code (there are many others).</p><p>I think this one is most fun and easy to use. Because here you go from just a personal project to production-grade.</p><ol><li><a href="https://youtu.be/DQdB7wFEygo?si=Zxd_1b7hdz-psZOQ">The Only Docker Tutorial You Need To Get Started</a> (Youtube) (Best Crash Course)</li></ol><p>2. <a href="https://www.youtube.com/watch?v=zQVYjmGFvv0">Docker for Machine Learning, AI, and Data Science</a> (YouTube)</p><p>3. <a href="https://github.com/veggiemonk/awesome-docker">Awesome Docker</a> (GitHub)</p><p>Honestly only these can be enough, but for course learners there are:</p><p>4. <a href="https://www.coursera.org/learn/virtualization-docker-kubernetes-data-engineering">Virtualization, Docker, and Kubernetes for Data Engineering</a> (Coursera) (Duke University)</p><p>5. <a href="https://www.coursera.org/learn/deploy-applications-docker-build-real-world-projects">Deploy Applications with Docker: Build Real-World Projects</a> (Coursera) (EDUCBA)</p><h4>3. Experiment Tracking &amp; Testing</h4><p>The concept of <strong>Experiment Tracking</strong> may look too advance but its rather simple and very useful.</p><p>Suppose you ran a model to house prices, first you used Linear Regression with some evaluation metrics and visualizations. Now you changed the model to Random Forest with different metrics and visualizations. How do you compare both? Probably not by undoing the code and running again (hilariously maybe you’re doing it).</p><p>To test and track your models like above we use <strong>MLFlow </strong>(there are other options) which is a platform that provides us with a good interface of different runs of a model. This concept alone, separates a one-file project with the complete end-to-end project</p><ol><li><a href="https://mlflow.org/docs/latest/ml/">MlFlow Documentation</a></li><li><a href="https://youtu.be/6ngxBkx05Fs?si=VFpkR3djNxUE4fLN">MLFlow Tutorial</a> (YouTube) (Crash Course)</li><li><a href="https://youtu.be/wb-ZxtIwSTA?si=p3Vl_hPeLLlFyqMM">MLFlow: Infrastructure for a Complete Machine Learning Lifecycle</a> (YouTube)</li><li><a href="https://www.udemy.com/course/mlflow-course/?srsltid=AfmBOoptqPpt_E1wZIePoH89LQwGssWqKelB2kI6Rzen_CQ8_DnrRc4k">MLFlow in Action</a> (Udemy) (Paid)</li><li><a href="https://www.coursera.org/learn/mlops-mlflow-huggingface-duke">MLOps Tools: MLflow and Hugging Face</a> (Coursera) (Paid)</li></ol><h3>Projects</h3><p>Learning new tools will get you nothing if you cannot test those tools and knowledge.
