<h3>What is Forward Propagation? Intelligence for Everyone(Part-2)</h3><p>This article continues my series, “Intelligence for Everyone.”</p><p>In the previous article, I explained what Neural Networks are, how each layer is responsible for the next layer’s inputs, and the types of Neural Networks. But in the previous article, I said that there are certain Knobs and Dials we have to turn to get certain output. Let’s look into that.</p><h3>What is Forward Propagation?</h3><p>Forward propagation refers to the flow of information from the input layer, through the hidden layers, to the output layer of a neural network. During this process, the input data is transformed by the parameters (weights and biases) of the network to produce the final output.</p><h3>Weights and Biases</h3><p>Each Neuron of every layer contains some information or a certain number between 0 and 1. These numbers are called <strong>Activations, </strong>which are also our input.</p><p>Suppose our model’s second layer detects the edges like in the image below. The parameters we adjust and experiment with to enhance how the model detects edges are known as <strong>Weights</strong>.<strong> </strong>These Weights may change many times before getting the right output. To see if there is an edge we also add some negative weights with the surrounding pixels such that the middle pixels (positive weights) will be green and the outer pixels (negative weights) will be red</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*EGRNM9EY_VM7BOqD0EMfkw.jpeg" /></figure><p>Let’s say we have Activations A1, A2, and A3... An. weights W1,W2,W3 . . .Wn.</p><p>Now calculate the dot product of the corresponding weights and activations because the weights have multiple dimensions (rows and columns) while Activations are in one column. The dot product will result in a weighted sum</p><p>We also need to add a limit to our neurons so they will only be activated when we need them. Let’s say we only want our neuron to be activated when the weighted sum is greater than 10. For this, we will add a <strong>Bias </strong>for <em>inactivity. </em>So add a “-10&quot; to the end of our weighted sum</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*y0_REX8BftR6NLW1cVixEw.png" /><figcaption>source: 3Blue1Brown (YouTube)</figcaption></figure><p>We also need some function that will squish the real number line and our weighted sum into the range of 0 and 1.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*k3TfibHbJalfMpT5DqVTow.png" /><figcaption>source: 3Blue1Brown (YouTube)</figcaption></figure><p>For this, we use non-linear functions like Sigmoid or Relu (Rectified Linear Unit). Remember how the model changes the <strong>Weights</strong> itself, These functions help change them.</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/850/1*1CLVA-S4urVGiG4mOV_SIg.png" /></figure><p>So after calculating the weighted sum, adding the bias, and applying the Sigmoid function, this is how the final equation would look like this</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*8X9lLFUyHOBcx716cUrWtg.jpeg" /></figure><p>This Python code will help you better understand how Forward Propagation works</p><pre>import numpy as np<br><br># Initialize weights, activations, and bias<br>weights = np.array([0.5, -0.2, 0.3, 0.8, -0.5])<br>activations = np.array([0.1, 0.4, 0.7, 0.3, 0.9])<br>bias = -10<br><br># Define the sigmoid function<br>def sigmoid(x):<br>    return 1 / (1 + np.exp(-x))<br><br># Forward propagation (weighted sum + bias)<br>weighted_sum = np.dot(weights, activations) + bias<br><br># Apply the sigmoid activation function<br>output = sigmoid(weighted_sum)<br><br># Print the output<br>print(f&quot;Weighted Sum: {weighted_sum}&quot;)<br>print(f&quot;Output after Sigmoid: {output}&quot;)</pre><p>Often this code is happening behind the model. However, it is crucial to know the math behind your model.</p><h3>Recap</h3><ol><li><strong>Activations </strong>are some number between 0 and 1 also known as inputs which are stored in a neuron</li><li><strong>Weights</strong> are the parameters that change consistently to adjust the learning capabilities of any model</li><li>Add a <strong>Bias</strong> for inactivity, which restricts neuron activation beyond a certain threshold.</li><li>We take the dot product of Weights and Activations and add them which results in a weighted sum</li><li>Squish the weighted sum using a non-linear function like Sigmoid or ReLu</li></ol><h4><strong>What’s Next</strong></h4><p>The above explanation was just one iteration in the Forward Propagation.
