<h3>Recap</h3><p>In the last article of this series, we learned about Gradient Descent, which is the process by which a Neural Network determines the cost function, a function that helps minimize the errors and makes the Neural Network make good decisions</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/1024/1*tyaOdOGOg0USKCh90zRyrA.png" /><figcaption>Source: By Mbali on <a href="https://www.analyticsvidhya.com/blog/2023/01/gradient-descent-vs-backpropagation-whats-the-difference/">Analytics Vidhya</a></figcaption></figure><h3>Feedback and Improve</h3><p>Remember how the cost function works? We take the average of all the cost functions (predicted value - True Value) and add them. In the BackPropagation we take all the cost values of a layer and feed it back to the previous layer which then assigns new weights and biases. Let’s make it simpler by only taking one example for now</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/225/1*689yOC_jyMzQNHdN8ekFOw.png" /></figure><p>Suppose we are at that stage where our Neural Network is giving random guesses and each output Neuron has a random value. The thing here is we can <strong>only control weights and biases. </strong>We want to tune our Network to increase the value of number 9 and decrease every other value.</p><p><strong>(Remember: Weights are the random values which are the strengths of the connections between Neurons and biases are the values given to limit the activations till a certain value is reached)</strong></p><p>Suppose the activation of 9 is 0.2 and 5 is also 0.2</p><p>We need to control and tell our Network that increasing the activation of 9 is more important than decreasing the same activations of other numbers. Let’s focus on number 9 having an activation of 0.2</p><pre>0.2 = sigmoid (W0A0 + W1Aa + ... + Wn-1An-1 + B)</pre><p>Now we have 3 different nudges we can change to increase the activation of 9.</p><ul><li>Increase the Bias</li><li>Increase the Weights</li><li>Change Activation (from the previous layer)</li></ul><p>Each weight has a different influence on the change of activation. The brightest (more valuable) ones can have the biggest effect since they are multiplied by the larger value</p><p>When we talked about Gradient Descent, we didn&#39;t just make the values lower and higher randomly. We care about which ones have the strongest impact on the values</p><p>Talking about the activations, To increase the activation of our number 9, we can see which Neurons have the bigger values and which ones have lower values. Then we can decrease the ones with lower values and increase the ones with higher values. That is for the activations of the previous layer</p><figure><img alt="" src="https://cdn-images-1.medium.com/max/801/1*mEAM5NthfeqEAykugyyicg.png" /><figcaption>Source: <a href="https://www.geeksforgeeks.org/backpropagation-in-neural-network/">GeeksForGeeks</a></figcaption></figure><h3>BackPropagtion (Propagating to the previous layer)</h3><p>Let’s zoom out a bit and notice that we were talking about only one number 9. Each number has its own set of weights and biases that decide which neurons should increase their value and which should decrease</p><p>Looping through the Neural Network, adjusting the weights and biases of every Neuron, and feeding them to the previous layer to adjust the activations is called <strong>BackPropagation. </strong>Because we are propagating in the backward direction</p><p>Taking the average of each number’s neuron value and adding them up is the value of the negative of the Gradient.</p><h3>Stochastic Gradient Descent</h3><p>But doing all the BackPropagation one by one on all the numbers requires great computational power. To make this process fast we do Stochastic Gradient Descent. In this process, we shuffle the data and make mini-batches of it, so that the computer reads and manipulates each batch at a time.</p><p>It is like stepping down a hill with no clue and taking small steps. Some steps are wrong, some are right. If we don&#39;t shuffle and mini-batch the data, It is like our Network is stepping down the hill in the right direction very slowly and carefully</p><p>Let’s summarize everything</p><h4><strong>Calculating the Error for Each Neuron in the Output Layer:</strong></h4><ul><li>The error is the difference between the predicted value and the true value (the cost function). Using this error, we compute how much each weight and bias contributed to the error in that specific neuron. This contribution is known as the <strong>gradient</strong> (from <strong>Gradient Descent</strong>).</li></ul><h4><strong>Propagating the Error Backward:</strong></h4><ul><li>Once we calculate how much each weight and bias in the output layer contributed to the error, we move backward to the previous layer. The idea is to <strong>adjust the weights and biases in the previous layer</strong> so that they contribute more effectively to reducing the error. Doing this for all the Neurons of each number (0 to 9) and adding them is called <strong>BackPropagation</strong></li></ul><h4>Adjusting Weights and Biases:</h4><ul><li>Now we update the new weights and biases and go for the next pass.</li></ul><p>The same process is repeated for every layer, propagating the error backward through the network, all the way to the input layer. This ensures that the entire network is “learning” how to adjust itself to minimize the cost function.</p><h3>Is this It?</h3><p>As we have learned about the architecture of a Neural Network, this is the beginning of Deep Learning. Next, we will learn how we can make a simple Neural Network in Python and learn about optimizers, learning rates, and different techniques that build upon these foundations to create powerful models.</p><p>— Umer Out</p><img src="https://medium.com/_/stat?event=post.clientViewed&referrerSource=full_rss&postId=00e2c9dfc068" width="1" height="1" alt="">
